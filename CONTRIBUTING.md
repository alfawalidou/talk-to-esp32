# Contributing

Contributions that improve ESP32 communication, examples, reliability, or documentation are welcome.

## Guidelines

- Keep changes focused and explain the hardware/firmware assumptions.
- Never commit Wi-Fi credentials, API keys, tokens, or private endpoints.
- Include reproduction steps for communication or connection bugs.
- Document any protocol, pinout, dependency, or configuration changes.
- Test examples on the intended ESP32 target when possible.

Pull requests should explain what changed, why, and how the change was validated.
